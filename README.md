# Mobin – Speech Therapy Mobile Application

## Software Description
**Mobin** is a mobile application designed to help children with speech disorders communicate effectively with others.

The system uses **Deep Learning (DL) models** to:
- Convert unclear speech into understandable words and sentences  
- Assist in early diagnosis  
- Provide interactive rehabilitation tools

## System Components

The system consists of two main layers:

### Front-End (Mobile Application)
- Built using Flutter  
- Handles user interaction and UI rendering  

### Back-End (Server & Processing)
Responsible for:
- Data validation  
- Speech processing  
- Diagnosis  
- Rehabilitation logic  
- Authentication  

---

## User Interface (Front-End)

### Authentication Flow
- Open App  
- Sign In (existing users)  
- Sign Up (new users)  

---

### Home Screen Features

After logging in, users can access:

- **Diagnosis Module** → Analyze speech and generate a report  
- **Voice Reconstructor** → Convert unclear speech into clear output  
- **Speech Cards** → Visual pronunciation training  
- **Word Matching** → Match spoken words with images  
- **Event Sequencing** → Arrange events in the correct order  
- **Letter Pronunciation (3D)** → Learn articulation using animations  
- **Oral Motor Exercises** → Strengthen speech muscles  
- **Articles Section** → Educational content about speech therapy  

---

## Back-End (Processing & Server)

### Authentication & Validation
- Uses API requests (POST)  
- Validates user input  
- Handles:
  - Account creation  
  - Login verification  
  - Error handling  

---

### Speech Processing & AI

- **Diagnosis Model** → Analyzes speech patterns  
- **Reconstruction Model** → Converts unclear speech to clear speech
